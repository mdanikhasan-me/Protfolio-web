## What this repo is

The full source of my personal site. My work, my writing, the Boilabin founder story, the services I take on, and every way to reach me. The front door is a live 3D identity sculpture sitting on a grid that refuses to stay still. That's the part people remember. The rest is the part that gets me work.

## The hard part

Putting a 3D sculpture on a website is easy. Making it behave on an average phone with mobile data is the actual project. Every Blender export, texture, and animation has to pass a performance budget before it is allowed on the page. The background moves and the sculpture reacts to your pointer, but the words never wait for any of that. All the important content is plain HTML, so if a device gives up on the fancy stuff, the site still says who I am and what I made.

## What's inside

```text
/writing    notes I can defend from first-hand experience
```

## Run it

Node 22 or newer.

```sh
npm ci
npm run dev
```
