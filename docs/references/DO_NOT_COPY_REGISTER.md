# Do-not-copy register

- Checkpoint: 1
- Purpose: convert reference admiration into enforceable originality boundaries

The references are for behavior, sequencing, information hierarchy, and performance lessons. They
are not an asset library or a style catalogue. “Do not copy” includes close tracing, recolouring,
renaming, swapping text while retaining composition, or combining recognizable signature pieces from
several references.

## Review test for later concepts

A concept fails originality review if a reasonable reviewer can identify a reference from the hero
silhouette alone, from a single transition still, or from the ordered storyboard without labels.

A concept also fails if its originality depends only on:

- a new colour palette;
- replacing one logo or character;
- mirroring the layout;
- changing type while keeping the composition;
- using the same object with different materials;
- shortening a copied motion sequence;
- or mixing two recognizable reference systems.

Checkpoint 2 must make the transformation rule, signature silhouette, chapter composition, motion
grammar, and Play relationship independently recognizable as Anik’s.
