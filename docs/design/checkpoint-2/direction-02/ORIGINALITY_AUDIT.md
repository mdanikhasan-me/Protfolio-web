## Elastic-effect independence test

The effect is allowed only if all of these remain true:

1. The pressure zone is organised around a thin vertical seam, not a rounded media aperture.
2. Deformation is primarily horizontal compression and controlled recovery, not viscous sagging,
   swelling, dripping, or blob merging.
3. Only a decorative visual layer bends; the semantic heading and surrounding facts stay rigid.
4. Chalk, cobalt, vermilion, and plum are used as register roles, not green-on-black imitation.
5. The sequence is register → press → transfer → release, not the reference's capsule-and-melt
   choreography.

Breaking any condition rejects the implementation rather than “refining” it.

## Cross-reference exclusions

- **Not a recolour:** removing colour preserves the full-width strata, unequal bands, vertical seam,
  and local baseline displacement.
- **Not mirrored:** a mirrored Website 02 still contains its capsule, face, and melt; none appear
  here.
- **Not renamed:** “ledger” is an enforceable layout law—every element registers to a baseline and
  one seam controls the only deformation.
- **Not a signature collage:** there is no central reference object, 3D chamber, wipe, robot, game
  world, orbit, or doodle layer.
- **Not generic AI output:** boards are deterministic SVG with real repository fonts and labelled
  pending media. There is no generated type, fake interface, stock glass, or invented metric.

## Still-frame and sequence tests

1. **Hero silhouette:** full-width typographic bands with one seam; no left-copy/right-object split.
2. **Transition still:** locally bent baselines around a vertical pressure line, not a melt, slit
   wipe, or expanding capsule.
3. **Ordered sequence:** alignment → pressure → band ownership → recovery.
4. **Material:** paper and ink, not glass, gel, smoke, chrome, grass, or star field.
5. **Typography:** repository Manrope and mono evidence labels, with bounded compression and stable
   recovery.

## Register coverage decision

Kinetic Ledger complies with DNC-028–037 and deliberately treats semantic/fallback design as the
primary art direction. It may proceed only if an early prototype proves legibility, DOM-order
fidelity, focus stability, and an unmistakably non-viscous deformation.
