## Field-versus-particle test

The system is valid only when a reviewer can identify the cause of each stable state:

- route focus bends a local current;
- content creates a calm repulsion corridor;
- project media creates an explicit boundary and colour falloff;
- progress changes density along one reading path;
- return leaves a faint deterministic wake.

Random drift, ambient snow, cursor-chasing particles, star-like backgrounds, and explosions are
rejected even if visually attractive.

## Cross-reference exclusions

- **Not a recolour:** in monochrome, directional marks, force-centred orientation, and calm content
  voids preserve the complete concept.
- **Not mirrored:** mirroring a reference object, chamber, capsule, or game world cannot produce a
  non-object field governed by several named constraints.
- **Not renamed:** the constraint data can be inspected, replayed, sampled as SVG, and used across
  viewport tiers.
- **Not a combination:** the system does not add reference melt, fracture, character, ribbon, orbit,
  or beacon to its field.
- **Not generic AI output:** deterministic code generates the boards and Blender study; media slots
  are truthful; abstract generation is exploratory only; no fake interface or face appears.

## Still-frame and sequence tests

1. **Hero silhouette:** broad directional current around an asymmetric calm void; no central object.
2. **Transition still:** marks anticipating and wrapping a growing evidence boundary; no white wipe,
   capsule, triangle, or tunnel.
3. **Ordered sequence:** sample → turn → clear → route → remember → settle.
4. **Material:** small opaque mineral/fibre marks with grazing light, not grass, stars, smoke,
   iridescence, or chrome.
5. **Typography:** rigid HTML in protected corridors, not giant copied words or deformed glyphs.

## Register coverage decision

Constraint Field complies with DNC-028–037 provided production enforces deterministic states,
explicit field causes, complete semantic HTML, and bundle isolation for Play. A generic particle
demo or reference-like space/grass treatment would fail the audit immediately.
