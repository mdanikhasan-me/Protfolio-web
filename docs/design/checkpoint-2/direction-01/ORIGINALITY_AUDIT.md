## Cross-reference exclusions

- **Not a recolour:** its identity would still be four round continuous paths and a quiet aperture
  in monochrome. No reference has that silhouette or topology.
- **Not mirrored:** flipping any reference does not produce a full-width multi-strand route with
  explicit continuity across case-study entry and return.
- **Not renamed:** the rule can be stated and mechanically tested: each strand remains continuous,
  roles are created by tension and routing, and return retraces the same topology.
- **Not an effects collage:** one system performs identity, focus, media framing, chapter change,
  progress, and return. There is no added melt, modular fracture, character, beacon, or orbit.
- **Not a generic AI portfolio:** there are no neon dashboards, floating UI screens, generated
  faces, fake metrics, glowing tech panels, or anonymous central orb. The factual work remains in
  semantic evidence regions.

## Still-frame and sequence tests

1. **Hero silhouette:** wide soft crossings with four round conduits; no triangle, letter, robot,
   capsule, angular module, or object-right split.
2. **Transition still:** an off-centre image aperture held open by continuous strands; no white
   wipe, slit, orbit, or expansion capsule.
3. **Ordered sequence:** tension → opening → threading → settling → retracing. This does not match
   any reference timeline.
4. **Material:** matte mineral ceramic, not iridescent glass, green gel, smoky rock, glossy robot,
   or grass/space.
5. **Typography:** stable Manrope with mono facts, not a copied giant word composition or deformed
   rounded face.

## Register coverage decision

Signal Weave complies with DNC-028–037: it is not a geometry-preserving recolour, signature-piece
collage, prompt-only image, stock model, fabricated content, noun-swapped copy, normal-page game
bundle, hover-only system, accessibility-afterthought, or desktop-capture claim. It may proceed to a
proof-of-law prototype only after user selection.
