## Input boundaries

- Scrolling never changes document distance or traps the user.
- Hover previews at most 8 px of control-point movement; keyboard focus gets the same hierarchy.
- Click, Enter, Back, and Escape create deterministic named states.
- Project imagery remains a labelled pending slot until approved assets are supplied.
