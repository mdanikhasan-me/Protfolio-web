# Workshop tokens and motion

## Material palette

- Paper `#EEE7D5`: the shared page surface.
- Bright paper `#F8F4E9`: menus and high-contrast reading surfaces.
- Carbon ink `#151A19`: text, engine housing, and primary actions.
- Cobalt `#234E9F`: service and commission signals.
- Oxidised teal `#176B67`: Boilabin and research-bay signals.
- Vermilion `#AC432E`: work archive and personal record signals.
- Safety yellow `#D2A124`: rare moving units and state markers.
- Metallic neutral `#747B76`: rails, measurements, and secondary structure.

Accent colours identify a workshop bay; they do not create unrelated page themes. Paper, ink,
typography, line work, spacing, and interaction behavior remain shared.

## Typography

- Fraunces 600: editorial display face.
- Manrope 400 and 600: body and interface text.
- IBM Plex Mono 500: measurements, statuses, and small technical labels.

All files are self-hosted through Fontsource. The browser downloads only the subsets used by the
rendered text.

## Shape language

Structure comes from rules, spacing, type scale, rails, pixel units, build plates, and measurement
marks. Corners stay square. Borders indicate an actual division or control, not a default wrapper
around every piece of content.

## Signature engine

The homepage engine is HTML and CSS. An abstract, non-facial silhouette occupies the portrait
channel until an approved source image exists. Selected authored units move along a short build path
into website, native software, and learning-system outputs.

The effect uses a view-linked CSS timeline when supported. It does not pin scrolling, start a
permanent animation loop, or move essential text. Mobile uses a stacked engine with no traveller
animation. Reduced-motion mode keeps the final composition and removes the movement.
