I built the UIU Discord Bot so students don't have to keep checking the notice board. It reads the notices from UIU's site and posts new ones in a Discord channel. It also shows the academic calendar and has slash commands. It's written in Python with discord.py.

The tricky part is deciding what's new. If the bot gets that wrong, it posts the same notice every time it checks, and nobody wants a channel full of repeats. So the bot keeps a record of every notice it has already sent.

I used Discord because UIU students are already there, asking each other questions. Posting the notice in the same place is easier than asking everyone to go to the website.

I don't have user numbers, so I'm not going to put any here. The code is public if you want to look.
