## A practical community tool

The UIU Discord Bot was built for United International University communities. Its job is practical:
bring useful university information into the place where a community is already talking.

The bot retrieves UIU notices, can post new notices automatically, provides academic calendar
information, and includes server utilities and slash commands. It uses Python and `discord.py`, with
notice scraping and duplicate prevention.

## The important behavior

Retrieving a notice is only the first step. An automated notice flow also has to avoid posting the
same item repeatedly. Duplicate prevention is therefore part of the product behavior, not a small
implementation detail.

The Discord integration gives people direct commands and can place new information into a server
without asking everyone to repeatedly check a separate source. The usefulness comes from reducing a
repeated task while keeping the result understandable.

## What the project proves

This project is evidence of Python work, scraping, Discord integration, automation, and attention to
a real community need. It is not presented with invented usage statistics or claims about how many
servers depend on it.

It also shows a different product shape from SoctuKit. One is an installed native Windows
application; the other coordinates an external source and a community platform. Both need clear
success conditions and visible handling for repeated work.
