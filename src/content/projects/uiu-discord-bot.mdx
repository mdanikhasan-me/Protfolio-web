## University notices without the daily portal check

UIU publishes notices on its public notice board, and students should not have to keep checking it
by hand. The UIU Discord Bot checks for new notices on a schedule and can post unseen ones into a
chosen Discord channel automatically.

It keeps a local history so the same notice is not posted twice, and it sends unseen notices in
order. The bot also provides academic calendar information and a small set of useful server
commands.

## Built for a real community

The project is written in Python with `discord.py`. It combines notice retrieval, duplicate
prevention, scheduled background checks, Discord commands, and local configuration in one practical
tool.

It is independent software, not an official UIU service. It does not sign in to UCAM or ask students
for their university password. That boundary is important: the bot should reduce a repetitive task
without pretending to replace the university's official systems.
