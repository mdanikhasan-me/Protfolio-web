## Social automation that follows the user's direction

SoctuKit is a Windows desktop app for managing social-media work from one place. The user decides
what should happen; the app can then help carry out that plan through likes, comments, replies, and
scheduled or automatic posts around a chosen topic.

I built it because most automation tools make the automated part obvious. The output feels shallow,
repetitive, or disconnected from what the user actually wanted to say. SoctuKit is built around a
more useful standard: automation should save the repetitive work without taking control away from
the person using it.

## A Windows product, not a browser mock-up

The app is built in C# and .NET 8 with WinUI 3, the Windows App SDK, XAML, and MVVM. It brings
account connection, activity visibility, drafting, publishing, and automation into a native desktop
workspace.

The surrounding product work matters too. OAuth tokens are stored in Windows Credential Manager,
important behavior is covered by tests, and the app ships through a proper Windows installer. Those
details are not the headline feature, but they are part of what makes desktop software dependable.
